# Bengali (Bangla) verse audio

Original MP3 recordings published by [The QURAN database](https://qurandb.com/)
in its optional Voice_Bengali.mdb download. The source does not identify the
recording’s translator or narrator. Its written-translation credit to Muhiuddin
Khan is not asserted as an audio credit. The owner explicitly authorizes this
publisher-attributed pack for Preview phone testing, with those limits disclosed.

Original audio bytes and ID3 metadata are preserved without re-encoding.
The publisher's README is retained as UPSTREAM-README.txt. Recordings remain
the work of their original producers; Huda claims no authorship or new license.
The publisher permits extraction for non-commercial applications.

SSSAAA.mp3 names map the complete6,236 canonical verses from IndexAyat;
empty source row6237 is omitted. manifest.json contains each original payload’s
length, SHA-256, Surah, ayah and global verse ID. This data-only branch keeps
recordings outside app/OTA bundles. App catalogs pin the immutable data commit.
